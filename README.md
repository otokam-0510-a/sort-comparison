# sort-comparison

クイックソートとマージソートをPHPで実装し、特徴と性能を比較したもの。

## セットアップと実行

```bash
composer install
composer test    # テスト(PHPUnit)
composer bench   # ベンチマーク(Markdown の表を出力)
```

要件: PHP 8.1 以上、Composer

## 方針

- 比較関数は全て同じ条件。`<=>`で比較する

## ディレクトリ構成

```
src/
  Compare.php        既定の比較関数
  QuickSort.php      クイックソート
  MergeSort.php      マージソート
tests/
  SortTest.php               2つのソートに共通のテスト
  MergeSortStabilityTest.php マージソートの安定性のテスト
bench/
  benchmark.php      ベンチマーク
```

## 実装したソート

### クイックソート

基準点を選び、左から「基準点以上」、右から「基準点以下」の要素を探して入れ替えながら、配列を2つのグループに分ける。
それぞれを再帰的に整列する(Wikipedia「クイックソート」の手順)。
基準点は、先頭・真ん中・末尾の3つの値の中央値にした。

| 項目 | 内容 |
|---|---|
| 平均計算量 | O(n log n) |
| 最悪計算量 | O(n²) |
| 安定性 | 不安定 |
| メモリ使用量 | O(log n) |

**良かった点**

- メモリ使用量が少ない(配列を作り直さず、その場で入れ替える)
- 平均的に速い。実測(10万件)では、整列済み・逆順でマージソートの約8割の時間、ランダム・重複の多い入力で約9割の時間

### マージソート

配列を半分に分け、それぞれを再帰的に整列し、整列済みの2つを、先頭から比べながら1つにまとめる(Wikipedia「マージソート」の手順)。

| 項目 | 内容 |
|---|---|
| 平均計算量 | O(n log n) |
| 最悪計算量 | O(n log n) |
| 安定性 | 安定 |
| メモリ使用量 | O(n) |

**良かった点**

- 入力の並びに関係なく、常にO(n log n)。最悪の場合がない
- 安定。等しい値の元の順序が保たれる

## テスト

`composer test`で実行する(15件)。

- 空配列 / 1要素 / 重複あり / 整列済み / 逆順 / 全要素同じ / ランダム
- 標準の`sort()`との結果一致
- マージソートの安定性

## ベンチマーク結果

条件: PHP 8.5.11、Mac。各条件を5回実行して中央値を採用(ウォームアップ1回を除く)。乱数のシードは固定。

| n | pattern | quickSort (ms) | mergeSort (ms) | usort (ms) |
|---|---|---|---|---|
| 1000 | random | 0.52 | 0.55 | 0.24 |
| 1000 | sorted | 0.30 | 0.47 | 0.17 |
| 1000 | reversed | 0.32 | 0.46 | 0.28 |
| 1000 | manyDuplicates | 0.50 | 0.58 | 0.28 |
| 10000 | random | 6.76 | 7.20 | 3.49 |
| 10000 | sorted | 3.87 | 5.34 | 2.56 |
| 10000 | reversed | 4.01 | 5.45 | 3.80 |
| 10000 | manyDuplicates | 5.99 | 6.89 | 3.68 |
| 100000 | random | 78.39 | 83.24 | 44.89 |
| 100000 | sorted | 47.39 | 60.13 | 32.90 |
| 100000 | reversed | 48.73 | 60.83 | 46.09 |
| 100000 | manyDuplicates | 73.16 | 78.57 | 47.92 |

**考察**

- どちらも、nが10倍になると、時間は約12〜13倍で、O(n log n)の伸び方になった
- 整列済み・逆順では、クイックソートが約2割速い
- ランダム、重複の多いケースでは、ほぼ同じ速度
- `usort`は、PHP本体(C言語)で動くため参考値である。自作との差は、アルゴリズムではなく、実行環境の差が大きい

## どちらを選ぶか

- 最悪のケースを避けたい、または安定性が必要 → マージソート
- 安定性が不要で、メモリを抑えつつ、平均速度を重視 → クイックソート
- 実務のPHPでは、組み込みの`sort`または`usort`を使う
